# Charisma Loop

منصة طلبات كاريزما عبر QR، قابلة للتحول إلى PWA تجاري، مع اقتراحات ذكاء اصطناعي ونظام نقاط أثر.

## المجلدات

- `web/prototype/index.html`: النسخة الحالية من تجربة الموقع الذكية.
- `web/prototype/menu-data.js`: ملف تعديل الأصناف والأسعار والصور والاقتراحات بدون لمس الواجهة.
- `web/prototype/menu-editor.html`: برنامج تعديل المنيو بالضغط، بدون كتابة كود.
- `web/prototype/control-panel.html`: برنامج الإدارة لتعديل بيانات الصفحة وإضافة عروض بتاريخ ووقت بداية ونهاية.
- `web/prototype/account.html`: تجربة تسجيل الدخول والتسجيل بالإيميل أو الهاتف مع كلمة سر وكود تفعيل واسترجاع تجريبي.
- `web/prototype/support.html`: مركز الدعم، رقم المطعم `11111`، مساعد حل سريع، وتتبع تذاكر الدعم التجريبية.
- `index.html`: نقطة الدخول التي يفتحها الدومين تلقائيًا.
- `site-config.js`: ملف إعداد الدومين المستخدم في مولد QR.
- `manifest.webmanifest` و`service-worker.js`: إعداد التثبيت والعمل السريع بعد الرفع.
- `qr-generator.html`: مولد QR للطاولات والمنيو وصفحة أثر الأكياس.
- `web/prototype/order-app-legacy.html`: نموذج الطلب السابق المحفوظ للمقارنة.
- `brand/logos`: نسخ الهوية والشعارات القابلة للتعديل.
- `brand/exports`: الأصول والصور المصدّرة.
- `menu/menu-design.html`: تصميم المنيو السابق.
- `archive/experiments`: تجارب الهوية والتصدير القديمة، بدون حذف.
- `pwa`: مكان ملفات PWA مثل manifest وservice worker.
- `backend`: مكان API وقاعدة البيانات في مرحلة المنتج التجاري.
- `docs/thesis-methodology.md`: توثيق فكرة المشروع والتنفيذ والنسخة التجارية.
- `docs/free-hosting-guide.md`: خطوات رفع النسخة مجانا على Netlify وتجهيز QR للمناقشة.

## مسار التطوير التجاري

1. تحويل `web/prototype/index.html` إلى واجهة PWA منظمة.
2. إضافة API وقاعدة بيانات للمنيو والطلبات والعملاء.
3. إضافة لوحة تحكم المطعم.
4. ربط QR للطاولات والطلبات.
5. تفعيل نقاط الأثر بعد اكتمال الطلب والتحقق منه.
6. إضافة الدفع والإشعارات والتقارير.

## دمج الذكاء الاصطناعي

النسخة الحالية تستخدم منطقًا محليًا بسيطًا للاقتراحات، من خلال هدف العميل وبيانات المنيو. عند تحويلها لمنتج حقيقي يكون المسار الآمن:

1. الواجهة ترسل إلى الخادم هدف العميل، الميزانية، الأصناف المتاحة، والحساسيات أو التفضيلات التي وافق العميل على حفظها.
2. الخادم يقرأ المخزون والأسعار وهامش الربح، ثم يرسل بيانات مختصرة إلى نموذج ذكاء اصطناعي عبر مفتاح محفوظ على الخادم فقط.
3. النموذج يعيد اقتراحات منظمة بصيغة JSON، والخادم يتحقق من السعر، المخزون، الحساسية، وقواعد العروض قبل عرضها.
4. إذا تعطل النموذج، يرجع النظام إلى الاقتراح المحلي بدل إيقاف الطلب.

لا يتم إرسال كلمة السر أو كود التفعيل أو بيانات الدفع إلى نموذج الذكاء الاصطناعي. الذكاء الاصطناعي يقترح، لكن الخادم هو الذي يقرر ما هو متاح وآمن ومربح للمطعم.

## تجهيز الربط بالدومين

ارفع مجلد `project` كاملًا إلى الاستضافة، وليس مجلد `web` وحده. بعد استلام الدومين:

1. افتح `site-config.js`.
2. استبدل `https://YOUR-DOMAIN.example` بالرابط الحقيقي، مثل `https://charisma-loop.com`.
3. ارفع الملفات مرة أخرى.
4. افتح `qr-generator.html` من الرابط المنشور، وسيظهر الدومين تلقائيًا في مولد QR.
5. أنشئ QR المنيو العام أو الطاولات أو صفحة أثر الأكياس.

النسخة الحالية Static Prototype. تعديل المنيو والعروض من `control-panel.html` و`menu-editor.html` يحفظ على نفس المتصفح فقط، لذلك عند تعديل المنيو قبل المناقشة يجب تنزيل نسخة احتياطية من برنامج الإدارة. لوحة تحكم متصلة بقاعدة بيانات وتعمل على كل الأجهزة تحتاج Backend في المرحلة التجارية.

الملفات الأصلية ما زالت محفوظة في المجلد الرئيسي كنسخة أمان.
